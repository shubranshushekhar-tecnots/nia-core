# reference

`DAX_Reference_Guide.xlsx` — DAX (Data Analysis Expressions) function/operator reference, kept as background material for Phase 6's transform-node directive.

`dax-reference.csv` / `combined-formula-patterns.csv` — programmatic exports of the
xlsx's "DAX Reference" and "Combined Formula Patterns" sheets (one row per sheet
row, generated via openpyxl; row counts verified to match the source sheets:
221 and 101 respectively). Regenerate from the xlsx if it's ever updated — these
are derived, not hand-maintained. The xlsx's other two sheets ("Operators &
Syntax", "Function Signatures") aren't exported; not needed by the Block 1
directive.
